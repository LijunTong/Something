在通用框架下，生成「设置」模块的独立页面。

【页面头部】
- 标题「设置」，副标题「所有配置保存在本机，不会上传到任何服务器」

【主体布局：左侧设置导航 + 右侧设置内容区】

1. 左侧设置导航 180px（竖排菜单）
   - 外观
   - 通知
   - 数据与存储
   - 邮箱账户
   - 订阅源
   - 快捷键
   - 关于

2. 右侧内容区（默认展示「数据与存储」，因为这是纯本地应用最重要的部分）

【数据与存储面板内容】
- 本地存储用量卡：
  - 总占用条形图，分 5 段颜色：日程、待办、邮件缓存、文章缓存、附件
  - 每段下方图例显示名称 + 占用大小（如「邮件缓存 128 MB」）
  - 总用量「共 412 MB」
- 自动备份区：
  - 开关「自动备份到本地目录」
  - 备份路径显示 + 「更改」按钮
  - 备份频率下拉（每天 / 每周 / 每次退出）
  - 「立即备份」按钮
- 导出区：
  - 四行按钮：「导出全部数据（JSON）」「导出日程（ICS）」「导出订阅源（OPML）」「导出邮件（EML/MBOX）」
- 导入区：
  - 「从备份文件恢复」按钮 + 说明小字「恢复会覆盖当前数据，请先备份」
- 加密备份区：
  - 开关「为备份文件设置密码」
  - 密码输入框
- 危险操作区（红色边框卡片）：
  - 「清空缓存」「清空回收站」「重置全部数据」三个按钮，最后一个为红色

【其他面板各画一个简要区块】

3. 外观面板
   - 主题：浅色 / 深色 / 跟随系统（三选一卡片）
   - 强调色：6 个色块可选
   - 字号：小 / 中 / 大 分段控件
   - 侧边栏：「始终展开 / 可折叠」开关

4. 通知面板
   - 全局开关「启用桌面通知」
   - 分模块开关列表：天气预警、日程提醒、待办到期、番茄结束、快递状态、新邮件
   - 免打扰时段：开始时间 - 结束时间
   - 通知隐私：「显示完整内容 / 仅显示有新消息」

5. 邮箱账户面板
   - 已配置账户列表：每个显示邮箱地址、协议（IMAP）、同步状态、最后同步时间、「编辑」「删除」按钮
   - 「+ 添加邮箱账户」按钮
   - 底部说明小字：「授权信息仅加密保存在本机」

6. 订阅源面板
   - 订阅源列表表格：名称、URL、分组、抓取频率、状态开关、删除
   - 「+ 添加订阅源」、OPML 导入/导出按钮

7. 快捷键面板
   - 快捷键列表表格：功能名 + 快捷键按键组合（如「全局搜索 ⌘K」「新建任务 N」「开始专注 F」）

8. 关于面板
   - 应用名称与版本号
   - 一句话说明：「纯本地个人效率工具集，无账户、无云同步、无 AI」
   - 「检查更新」按钮
   - 「查看开源许可」

【页面底部固定提示条】
- 灰底小字：「⚠ 本应用不提供账户体系与云同步，所有数据仅保存在本机。请定期备份，卸载或清除浏览器数据可能导致数据丢失。」
