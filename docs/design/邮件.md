在通用框架下，生成「邮件」模块的独立页面，采用经典三栏邮件客户端布局。

【页面头部】
- 标题「邮件」，副标题「未读 5 · 共 2 个账户 · 最后同步 2 分钟前」
- 右侧操作：「同步」按钮（带旋转图标）、「+ 写邮件」主按钮、设置图标

【主体布局：三栏】

1. 左栏 200px「账户与文件夹」
   - 账户区块：
     - 工作邮箱（zhangsan@company.com）—— 未读 3
       - 收件箱（3）、星标、已发送、草稿（1）、垃圾箱、自定义文件夹「项目」
     - 个人邮箱（me@personal.com）—— 未读 2
       - 收件箱（2）、星标、已发送、草稿、垃圾箱
   - 顶部有「统一收件箱」入口，显示总未读 5
   - 每行显示文件夹图标 + 名称 + 未读数角标
   - 当前选中「工作邮箱 - 收件箱」高亮

2. 中栏「邮件列表」（约 340px 宽）
   - 顶部工具栏：全选复选框、刷新、批量操作图标（已读 / 删除 / 移动 / 加标签）
   - 搜索框「在当前文件夹中搜索」
   - 邮件列表行，每条 3 行结构：
     - 第一行：发件人名称（未读加粗）+ 右侧时间（09:12）
     - 第二行：邮件主题（未读加粗）
     - 第三行：正文摘要一行截断 + 右侧附件回形针图标
     - 左侧：未读圆点 + 星标图标
   - 至少 6 封邮件，其中 3 封未读、1 封带附件、1 封已加标签
   - 示例邮件：
     - 张三「项目评审会议纪要」有附件，未读
     - 物流通知「您的快递已到达驿站」未读
     - 李四「本周需求变更确认」已读
     - HR「关于年度体检安排的通知」未读，带「重要」标签
   - 当前选中某封邮件时，行背景高亮

3. 右栏「阅读窗格」（自适应宽）
   - 顶部工具栏：回复、全部回复、转发、星标、标记未读、移动到文件夹、删除、打印、「…」更多
   - 邮件头部：
     - 大标题（邮件主题）
     - 发件人行：头像占位 + 姓名 + 邮箱地址 + 时间
     - 收件人行：收件人、抄送（可折叠）
     - 标签行：显示「重要」标签
   - 安全提示条（黄色浅底）：「远程图片已被拦截，以保护您的隐私」+ 「显示图片」按钮
   - 正文区：段落文字 + 一个附件卡片（文件名、大小、下载按钮）
   - 底部：快捷回复输入框 + 「回复」按钮

【需额外画出的弹窗/状态】

4. 写邮件弹窗（右下角悬浮窗形式，或居中弹窗）
   - 顶部：标题「新邮件」+ 最小化 / 关闭图标
   - 发件账户下拉（选择工作邮箱 / 个人邮箱）
   - 收件人、抄送、密送输入行
   - 主题输入行
   - 富文本工具栏：加粗、斜体、下划线、列表、链接、附件
   - 正文编辑区
   - 底部：「发送」主按钮、「保存草稿」、「定时发送」、附件图标

5. 规则管理抽屉
   - 标题「收件规则」
   - 规则列表，每行：规则名 + 条件摘要 + 动作摘要 + 启用开关
   - 示例：「发件人包含 @company.com → 加标签『工作』并通知」
   - 按钮：「+ 新建规则」

6. 其他状态
   - 同步中：顶部细进度条 + 「正在同步…」
   - 离线：顶部提示条「当前离线，展示本地缓存邮件」
   - 空文件夹：「此文件夹暂无邮件」
   - 账户配置入口：左栏底部「+ 添加邮箱账户」（点击后为配置表单，IMAP/POP3 + SMTP、授权码、测试连接）
