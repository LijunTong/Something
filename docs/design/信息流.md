在通用框架下，生成「信息流」模块的独立页面，采用三栏阅读器布局。

【页面头部】
- 标题「信息流」，副标题「12 篇未读 · 共 8 个订阅源 · 最后抓取 10 分钟前」
- 右侧操作：「刷新全部」按钮、「+ 添加订阅源」按钮、更多菜单（OPML 导入 / OPML 导出 / 规则过滤设置）

【主体布局：三栏】

1. 左栏 200px「订阅源导航」
   - 智能分类：全部文章（128）、未读（12）、收藏（23）、稍后读（7）
   - 订阅源列表（按分组）：
     - 分组「科技」：少数派（5）、36氪（3）
     - 分组「设计」：设计周刊（2）、UX Collective（2）
     - 分组「独立博客」：阮一峰的网络日志、某独立博客
   - 每行显示源名称 + 未读数角标
   - 底部：「+ 新建分组」
   - 当前选中「未读」高亮

2. 中栏「文章列表」（约 320px 宽）
   - 顶部筛选行：未读 / 全部 / 收藏 / 稍后读 分段控件
   - 文章条目列表，每条约 3 行高：
     - 第一行：来源名称（小字灰色）+ 右侧发布时间（如「10 分钟前」）
     - 第二行：文章标题（加粗，最多两行）
     - 第三行：摘要片段（灰色小字，一行截断）
     - 未读文章左侧有主色竖条标记，已读文章无标记且标题变灰
   - 至少 6 篇文章，其中 1 篇为当前选中（背景高亮 #f0fdfa）
   - 底部：「加载更多」按钮

3. 右栏「阅读器」（自适应宽）
   - 顶部工具栏：返回、字体大小 A- / A+、暗色模式切换、收藏星标、稍后读、「…」更多（标记已读 / 转为待办）
   - 文章头部：大标题、来源、作者、发布时间
   - 正文区域：段落文字示例，包含一个小标题和一个引用块
   - 正文底部：原文链接、「打开原文」

【需额外画出的弹窗/状态】

4. 添加订阅源弹窗
   - 输入框「RSS / Atom 链接」
   - 分组下拉、抓取频率下拉（每小时 / 每 6 小时 / 每天）
   - 按钮：「验证链接」「添加」

5. 规则过滤设置页（可画成抽屉）
   - 规则列表：每行显示规则名 + 条件摘要 + 启用开关
   - 示例规则：「标题包含『招聘』→ 自动标为已读」「来源为『36氪』→ 不通知」
   - 按钮：「+ 新建规则」

6. 空状态
   - 中栏为空时：「该订阅源暂无文章」+「刷新」按钮
