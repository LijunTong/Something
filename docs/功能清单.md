## 本地数据与架构

**状态**：已完成 · **进度**：13/13

**源码**：主进程 electron/main.cjs；IPC electron/ipc/registry.cjs；preload electron/preload.cjs；数据库 electron/db/；迁移 migrations/001-012。

- [x] Electron 三进程：main / preload / renderer，开启 contextIsolation，渲染进程无 Node 权限
- [x] IPC 白名单：preload 只暴露 window.api.<domain>.<method>，禁止通用 invoke 透传
- [x] 入参校验：所有 IPC 入参在主进程用 zod 校验，非法入参返回结构化错误
- [x] SQLite：better-sqlite3 只在主进程访问，迁移脚本 001-012 版本化执行
- [x] 数据分层：service 按 domain 拆分，SQL 只在 service 内，写操作包 withTx 事务
- [x] 数据模型：待办/日程/番茄钟/天气/信息流/快递/邮件/通知/设置/操作日志/项目计划共 20 余张表
- [x] 纯本地：无账户、无云同步，数据库与缓存位于 %APPDATA%\Something
- [x] 自动备份：启动、运行中每 30 分钟检查、退出时触发，可加密并限制保留份数
- [x] 导出/恢复：JSON 导出与导入覆盖，导入前提示风险
- [x] 桌面能力：单实例锁、系统托盘菜单、关闭/最小化到托盘、开机自启
- [x] 应用更新：检查 GitHub Release、下载 exe 并安装，展示下载进度
- [x] 无 IPC 降级：浏览器预览下所有 call() 带 fallback，页面不白屏
- [x] 可观测性：结构化日志与 operation_log 操作记录
