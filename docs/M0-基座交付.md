## 已知环境限制

- 本机 Node ABI 为 147，Electron 33 需要 130。`better-sqlite3` 已用 `electron-rebuild` 编为 Electron ABI，因此在纯 Node 下加载会报 ABI 不匹配——这是预期行为，桌面运行时正常。
- 本机 esbuild 服务无法清理系统临时文件（`Access denied`）。已在 `vite.config.js` 用进程内 `transformSync` 插件替代，并在非生产构建关闭 minify；功能不受影响，生产打包需在有写权限的环境重开 minify。

## 运行方式

```
npm run dev     # 浏览器预览（无 IPC，会提示未在 Electron 中运行）
npm run build   # 构建前端
npm start       # 启动 Electron 桌面应用（需先 build 或已在 dev）
npm run rebuild # 重新为 Electron 编译 better-sqlite3
```
