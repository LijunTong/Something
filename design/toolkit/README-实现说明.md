# 效率工具集 · 功能实现交付说明

## 已完成
按 `docs/feature-design.md` 的功能规划与 `design/toolkit` 的 9 屏原型，完成 MVP 全量 + 部分 P1 的具体功能实现。

- 功能梳理文档：`docs/implementation-plan.md`（范围、数据模型、逐屏映射、联动、差异处理）
- 技术栈：原生 HTML/CSS/JavaScript + localStorage，零依赖、零构建，**双击 HTML 即可运行**
- 数据层：`design/toolkit/js/store.js`（统一 state + 发布订阅 + 跨标签页同步 + 导入导出/重置）
- 通用工具：`design/toolkit/js/ui.js`（toast、确认框、主题、全局搜索 Ctrl+K、快捷添加/通知跳转）
- 9 屏各自脚本：`js/{home,todo,pomodoro,schedule,weather,feed,parcel,mail,settings}.js`，已注入各 HTML 的 `</body>` 前

## 运行方式
直接双击 `design/toolkit/home.html`，或任意模块页。数据在浏览器 localStorage，key=`toolkit.state.v1`。设置页可导出 JSON 备份、重置。

## 各模块已实现功能
- **首页**：8 卡读真实数据、侧栏角标联动、城市切换、待办勾选、通知已读/恢复、全局搜索。
- **天气**：当前天气随城市切换、多城市抽屉（切换/增删/搜索）、刷新走缓存骨架屏、预警查看。
- **日程**：周视图事件按数据渲染、分类显隐、新建/详情/编辑备注/删除、ICS 导出、当前时间线、开始专注/转待办。
- **番茄钟**：真实倒数计时、开始/暂停/继续/放弃/跳过、专注时长设置、番茄点阵、统计与会话、全屏专注、状态恢复、中断记录。
- **待办**：快速添加、清单侧栏、4 种过滤、完成/子任务、列表/看板、详情、新建、转日程/转番茄。
- **信息流**：未读/收藏/稍后读过滤、阅读器（字号/暗色/收藏/稍后读/转待办）、订阅源增删、规则抽屉。
- **快递**：状态分组、公司识别、轨迹抽屉、复制单号、隐私脱敏、归档、生成取件待办。
- **邮件**：文件夹导航、列表、阅读、星标/未读/删除、本地搜索、远程图拦截、附件、回复/撰写、收件规则、转待办。
- **设置**：模块开关、主题/强调色/字号、通知开关、JSON/ICS/OPML 导出、备份/恢复/重置确认、API/邮箱配置位。

## 联动
待办⇄日程⇄番茄、快递/信息流/邮件→待办、天气→首页、全局通知角标、跨屏 localStorage 同步。
